string s1InputName,
string rsOperandVariableName )
inlinestatic

Creates a single RS network intended for use inside a LAD-language FB.

Note: XmlNetwork must be constructed with MEPlang.FBD even for LAD blocks. LAD and FBD share the same underlying graph XML schema in TIA Portal's Openness import format. Passing MEPlang.LAD to XmlNetwork produces XML that TIA Portal rejects with a System.Xml.XmlException at import time. The block-level ProgrammingLanguage attribute set on the XmlNetwork owner block is what causes TIA Portal to display it in LAD view.

The RS Q output is left explicitly unconnected (null) because LAD does not use a downstream Coil element to write the result — the operand pin is the bit-memory output.

Parameters
rInputNameVariable name connected to the R (reset) input.
s1InputNameVariable name connected to the S1 (set) input.
rsOperandVariableNameVariable name written by the RS operand pin (bit memory).

Generates a LAD Function Block (FB) with two chained RS networks and one SCL assignment network.

The generated block contains:

  • Network 1: RS driven by InputBool_R / InputBool_S1; result stored in RSOperand.
  • Network 2: RS driven by InputBool_R2 / RSOperand; result stored in RSOperand2.
  • Network 3: SCL assignment #TempVariable := #RSOperand, demonstrating mixed-language networks.

LAD import mechanism: Networks are built with MEPlang.FBD because XmlNetwork only generates valid graph XML in FBD mode. After the initial import the block is exported, every CompileUnit-level ProgrammingLanguage element is changed from FBD to LAD, and the block is reimported so TIA Portal displays it correctly as LAD. SCL networks are left unchanged.

Rewrites the wiring inside a single FlgNet element from FBD topology to LAD topology:

  • AND ("A") Parts are expanded into a series Contact chain; negated AND inputs become NC Contacts; the (unsupported) negated out is dropped.
